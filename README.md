# 坦克大战 Tank Battle 🚀

一个用纯 HTML + Canvas + JavaScript 实现的经典坦克大战游戏，无需任何依赖，打开即玩！

## 🎮 在线游玩

直接用浏览器打开 `index.html` 即可，或者将仓库开启 GitHub Pages 后在线游玩。

## 操作方式

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动坦克 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |
| R | 重新开始 |

## 游戏特性

- 🎯 经典坦克大战玩法：消灭所有敌人、保护基地（🦅 老鹰）
- 🧱 多种地形：砖墙（可摧毁）、钢墙、河流、森林
- 🤖 敌人 AI：追踪玩家、进攻基地，血量随关卡提升
- 📈 无限关卡，难度递增
- 🔊 Web Audio 合成音效，无外部资源
- ⚡ 单文件实现，零依赖

## 技术栈

- HTML5 Canvas
- 原生 JavaScript（无框架、无依赖）
- Web Audio API（程序化音效）
